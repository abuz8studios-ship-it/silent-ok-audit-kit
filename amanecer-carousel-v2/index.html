The rule

Ending state beats keyword hits

  • Read the whole final message, not its last trigger word.
  • Check negation, recovery, and completion before calling it stuck.
  • Treat finished subagent reports as output the parent already consumed.
  • End with one question: what artifact exists now?
State, not vocabulary04 / 08
Why it stays hidden

Silent failures do not look red

  • Paused jobs disappear from many failure views.
  • An overdue job can keep a calm last-known status.
  • last_status: ok proves a process ended — not that anything shipped.
  • A profile cross-check can stay open while volume keeps moving.
Green is not evidence05 / 08
Before any claim

The full verification gate

  • Use it before talking about it.
  • Read the exact parent and check every fact.
  • Read the draft back from the actual field.
  • Reopen the fresh status page or artifact.
  • Decode or resolve the ID in a separate runtime.
  • Cross-check the profile or history listing.

Anything less is partial — and gets labeled partial.
