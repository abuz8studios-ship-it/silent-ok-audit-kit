# Full verification gate

## Before posting or claiming done

- [ ] I used the tool/product myself, or this is clearly labeled as an unused recreation.
- [ ] I read the exact parent/source, not a summary of it.
- [ ] Every number, date, price, and status came from a fresh source in this run.
- [ ] The draft was read back from the actual composer/artifact.
- [ ] Credit is present: thanks, @ source where public, and relevant # tag.
- [ ] A required human sign-in is open **and named**, or none is needed.

## After shipping

- [ ] Fresh target page shows the exact unique hook.
- [ ] Status/object ID decodes or resolves in a separate runtime/view.
- [ ] Profile, history, or listing cross-check contains the same ID.
- [ ] No tombstone/deleted/error state.
- [ ] Volume counts use unique verified IDs only.

`VERIFY_OK` or `FRESH_OK` from one screen is **partial** unless every box above is checked.
Partial stays labeled partial. A missing sign-in or cross-check stops the claim, not the work log.
